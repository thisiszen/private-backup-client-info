rclone personal encrypted backups

A private backup utility for its owner's personal use. It runs locally and uses rclone to store encrypted backups in a dedicated folder in the owner's Google Drive.

Google Drive access

The utility requests the limited drive.file permission. This allows it to create and manage files that it creates or that the owner explicitly opens with it. It does not request access to all files in Google Drive.

Backup contents are encrypted locally before upload. The utility uses file metadata and reads uploaded encrypted files to check that backups were transferred correctly. Recovery keys remain separate from the uploaded backups.

This is a personal utility, not a public backup service. Access can be revoked through the owner's Google Account connections settings.

Privacy policy

Terms of use

This utility is intended only for the account owner's personal backups. Use of Google Drive remains subject to Google's applicable terms. The owner controls backup retention and may revoke the utility's access at any time.

This page describes the utility. It contains no backup files, credentials or recovery keys.
