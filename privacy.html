Privacy policy

For rclone personal encrypted backups.

Purpose and data access

This utility runs on its owner's computer to make and recover personal encrypted backups. It uses Google's limited drive.file permission to create and manage files that it creates or that the owner explicitly opens with it. It uses Google account identity to verify the intended backup account, and file metadata and encrypted file contents to upload, list, verify and recover backups.

Storage and protection

Backup contents are encrypted locally before upload to Google Drive. Recovery keys are kept separately from uploaded backup data. OAuth credentials are stored locally in protected configuration so the utility can perform backups without repeated sign-in. Backup files and their metadata are stored by Google Drive under the owner's account.

Use and sharing

Google user data is used only to operate and verify the owner's backups. The utility does not sell this data, use it for advertising or use it to train AI models. It does not send backup data to the rclone project's servers. Data is transferred directly between the owner's computer and Google Drive. This informational website has no analytics or advertising scripts.

Retention and control

The owner controls backup retention. Stored backup files remain until the owner deletes them. Access may be revoked in Google Account connections settings. Revoking access stops future authorized access by the utility; it does not itself delete existing backup files. The owner can remove those files separately in Google Drive.

Contact

This utility is maintained by its account owner. The configured support contact is shown in Google's authorization interface.

The utility's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
